# Ecommerce Sales & Customer Analytics Dashboard

LIVE LINK: https://public.tableau.com/views/olist_ecommerce_analytics/Dashboard1?:language=en-US&publish=yes&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link 

## Project Overview
Built an end-to-end ecommerce analytics project using PostgreSQL, SQL, and Tableau to analyze customer behavior, sales trends, and product performance using the Olist ecommerce dataset.

## Tools Used
- PostgreSQL
- SQL
- Tableau
- Olist Ecommerce Dataset

## Key Analytics Performed
- Revenue Analysis
- Monthly Sales Trend Analysis
- Customer Segmentation
- Top Customer Analysis
- Product Category Analysis
- Revenue Share Analysis
- Customer Retention Analysis

## SQL Concepts Used
- Joins
- CTEs
- Window Functions
- CASE WHEN
- Aggregations
- Running Totals
- MoM Growth Analysis

## Dashboard Features
- KPI Cards
- Revenue Trend Visualization
- Top Product Categories
- Customer Insights
- Interactive Filters

## Key Business Insights
- Revenue exceeded 13.5M across 99K+ orders.
- Revenue peaked during mid-year months indicating seasonal demand.
- Repeat customer rate appears low, suggesting retention opportunities.
- A few product categories contribute majority of total revenue.
- High-value customers contribute disproportionately higher revenue.

## Business Recommendations
- Improve customer retention through loyalty programs.
- Focus marketing efforts on high-performing categories.
- Diversify category offerings to reduce revenue dependency.
- Analyze seasonal sales patterns for inventory optimization.
